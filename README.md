# LoL Lang Switcher

**English** · [Français](README.fr.md) · [日本語](README.ja.md)

Launch League of Legends in the language of your choice (Japanese, French…) from a desktop shortcut,
with a small animated splash and no black console window. Optionally starts a companion app
afterwards (Porofessor, Blitz, OP.GG…).

## Folder contents

| File | Role |
|---|---|
| `install.bat` | **Double-click this**: detects install locations, generates `config.json`, creates the desktop shortcuts |
| `config.json` | Riot paths + companion app. Generated by `install.bat`, editable by hand if detection is not enough |
| `locales.json` | Catalogue of languages offered at install time (Riot code + displayed label) |
| `launch-lol.ps1` | The launcher: closes the Riot Client, forces the language, relaunches the game (+ companion app) |
| `detect-config.ps1` | Called by `install.bat`: detects Riot and the companion app (Porofessor, Blitz, OP.GG) |
| `create-shortcuts.ps1` | Called by `install.bat`: language picker dialog, then one `.lnk` per language on the desktop (falls back to this folder if the desktop is not writable) |
| `make-flag-icons.ps1` | Tool: regenerates the flag icons in `ico/` from the Riot icon (not needed for normal use) |
| `ico/` | Icons: original Riot icon + one flag variant per language (`league-of-legends-xx.ico`) |

The `League of Legends XX` shortcuts (one per selected language) are created on the desktop by `install.bat`.

## Installing on a new machine

1. Copy this folder anywhere (e.g. `Documents\scripts\lol`) — **without** `config.json` if it comes
   from another machine, so detection can run.
2. Double-click **`install.bat`**. It:
   - detects the Riot Client (via `RiotClientInstalls.json`, Riot's official file) and the first
     installed companion app among Porofessor (Overwolf), Blitz, OP.GG — otherwise none;
   - writes `config.json` (never overwritten if it already exists: manual settings are preserved);
   - opens a **dialog**: tick the languages you want (JP and FR pre-ticked the first time, then
     whatever is already installed) and click "Install";
   - creates one `League of Legends XX` shortcut per ticked language on the desktop, and removes
     those of unticked languages (required even without changes: `.lnk` files embed absolute paths).
     If the desktop is not writable (protected folder, OneDrive…), they are created in this folder instead.
3. Double-click the shortcut of the language you want.

To add or remove languages later: run `install.bat` again and tick/untick.

If detection got it wrong or you use another app: edit `config.json` (see below) and run `install.bat`
again. To force a fresh detection: delete `config.json` and run again.

The first time you launch in a new language, the Riot Client downloads the text + voice pack
(a few hundred MB). This is expected.

## `config.json`

```json
{
  "riotClientPath": "C:\\Riot Games\\Riot Client\\RiotClientServices.exe",
  "productSettingsPath": "C:\\ProgramData\\Riot Games\\Metadata\\league_of_legends.live\\league_of_legends.live.product_settings.yaml",
  "companionApp": {
    "enabled": true,
    "name": "Porofessor",
    "path": "C:\\Program Files (x86)\\Overwolf\\OverwolfLauncher.exe",
    "arguments": "-launchapp pibhbkkgefgheeglaeemkkfjlhidhcedalapdggh -from-startmenu"
  }
}
```

Backslashes must be doubled (`\\`) — it's JSON.

| Key | Description |
|---|---|
| `riotClientPath` | Path to `RiotClientServices.exe`. By default in `C:\Riot Games\Riot Client\`. |
| `productSettingsPath` | The yaml file where Riot stores the LoL language. Always under `C:\ProgramData\Riot Games\Metadata\…` unless the install is unusual. |
| `companionApp.enabled` | `true` to start an app after the game, `false` to start none. |
| `companionApp.name` | Name shown in the splash. Cosmetic. |
| `companionApp.path` | Executable to start. |
| `companionApp.arguments` | Launch arguments. Empty string `""` if none. |

If `path` does not exist on the machine, the launcher skips it and shows a warning in the splash —
the game starts anyway.

### Companion app examples

**None**:
```json
"companionApp": { "enabled": false }
```

**Porofessor** (via Overwolf) — default configuration above.

**Blitz**:
```json
"companionApp": {
  "enabled": true,
  "name": "Blitz",
  "path": "C:\\Users\\<user>\\AppData\\Local\\Programs\\Blitz\\Blitz.exe",
  "arguments": ""
}
```

**Another Overwolf app**: keep `OverwolfLauncher.exe` and replace the identifier after `-launchapp`
(visible in the properties of the shortcut the app created in the Start menu).

**Make an app auto-detectable**: add an entry to `$CompanionCandidates` in `detect-config.ps1`
(name, path, arguments). List order is priority order.

## Languages

Every language Riot offers is in `locales.json` and can be ticked at install time. The shortcut is
named `League of Legends XX` (XX = country part of the code: `ja_JP` → JP, `ko_KR` → KR).

Icon: `ico/league-of-legends-xx.ico` (lowercase xx) — every language in the catalogue has its flag.
If the icon is missing, the original Riot icon is used.

For a language missing from the catalogue (new Riot locale):
1. add a line to `locales.json` with the exact code as it appears in `available_locales` of the yaml file;
2. (optional) add the flag drawing to `$FlagDrawings` in `make-flag-icons.ps1` and run
   `powershell -NoProfile -ExecutionPolicy Bypass -File make-flag-icons.ps1 -Locales xx_XX`.

Usage without the dialog (scripting, deployment):
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File create-shortcuts.ps1 -Locales ja_JP,ko_KR
```

## How it works

The Riot Client's "Language" setting only changes the launcher, not the game. The LoL language is read
from `settings.locale` in `product_settings.yaml`, which the Riot Client rewrites every time it closes.
So the launcher does, in order:

1. Close the Riot Client and the LoL client if they are running (otherwise the change would be overwritten).
2. Rewrite `settings.locale` with the requested language (`default_locale`, managed by Riot, is left alone).
3. Start the Riot Client with `--locale=xx_XX` as well, for good measure.
4. Start the companion app if enabled.

## Troubleshooting

- **The game stays in the old language**: the Riot Client was still running during the rewrite.
  The launcher closes it itself, but if a process is stuck, close it by hand (tray icon → Quit) and retry.
- **Nothing happens on double-click**: open a PowerShell terminal in the folder and run
  `.\launch-lol.ps1 -Locale ja_JP` to see the error (config file not found, wrong path…).
- **Garbled characters in the splash** (`Ã©`, `â€¦`): `launch-lol.ps1` was re-saved without a BOM.
  It must be **UTF-8 with BOM** (VS Code: status bar → encoding → "Save with Encoding").
- **Shortcut icon not up to date**: Windows icon cache. Right-click → Refresh in the folder,
  otherwise sign out/in.
- **Test without launching the game**: `.\launch-lol.ps1 -Locale ja_JP -DryRun -YamlPath copy.yaml`
  shows the splash and rewrites the copy, without closing or launching anything.
