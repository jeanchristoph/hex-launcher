**Windows only, for now** (Windows 10/11, PowerShell 5.1 included — macOS is not supported).

League of Legends launcher helper for Windows: start the game in the language of your choice
(Japanese, French…) from a desktop shortcut with a small animated splash and no black console window,
and manage your **companion apps** (Porofessor, Blitz, OP.GG, Mobalytics) — tick the ones you want,
they get installed for you, and you get one shortcut per language × companion app
(`League of Legends JP - Blitz`, `League of Legends JP - Porofessor`…).

## Folder contents

| File | Role |
|---|---|
| `install.bat` | **Double-click this**: detects install locations, lets you pick the companion apps, then the languages and shortcuts |
| `config.json` | Riot paths + list of companion apps. Generated by `install.bat`, editable by hand if detection is not enough |
| `locales.json` | Catalogue of languages offered at install time (Riot code + displayed label) |
| `companion-apps.json` | Catalogue of companion apps: how to detect, install, uninstall and launch each one, and who signs its binaries |
| `launch-lol.ps1` | The launcher: closes the Riot Client, forces the language, relaunches the game (+ the companion app given by `-Companion`) |
| `detect-config.ps1` | Called by `install.bat`: detects Riot and the companion apps already installed |
| `manage-companion-app.ps1` | Called by `install.bat`: companion app picker, installs the missing ones, uninstalls on request |
| `create-shortcuts.ps1` | Called by `install.bat`: language + companion picker, then one `.lnk` per combination on the desktop (falls back to this folder if the desktop is not writable) |
| `lib/companion-app.lib.ps1` | Shared functions: catalogue, detection through the registry (read-only), uninstall command, Authenticode signature check |
| `lib/launch-config.lib.ps1` | Shared functions: reading/writing `config.json`, migration of the old single-app format |
| `lib/splash.lib.ps1` | Shared animated splash (game launch, companion app install) |
| `tests/` | Pester tests (`Invoke-Pester -Path tests`) |
| `make-flag-icons.ps1` | Tool: regenerates the flag icons in `ico/` from the original base icon (not needed for normal use) |
| `ico/` | Icons: original base icon (H monogram) + one flag variant per language (`hex-launcher-xx.ico`) |

## Installing on a new machine

1. Copy this folder anywhere (e.g. `Documents\hex-launcher`) — **without** `config.json` if it comes
   from another machine, so detection can run.
2. Double-click **`install.bat`** (never "Run as administrator": the tool refuses, on purpose). Three steps:
   - **[1/3] Detection** — finds the Riot Client (via `RiotClientInstalls.json`, Riot's official file) and every
     companion app of the catalogue already installed, then writes `config.json` (never overwritten if it already
     exists: manual settings are preserved);
   - **[2/3] Companion apps** — a dialog lists every app of the catalogue with checkboxes, pre-ticked from your
     previous choice (or from what is installed). Ticked apps that are missing get installed. A separate box,
     **unticked by default**, lets you also uninstall the unticked apps that are present. A confirmation lists
     exactly what will happen; "Annuler" keeps everything as is;
   - **[3/3] Shortcuts** — a dialog to tick the languages (JP and FR pre-ticked the first time) and the companion
     apps to combine. One shortcut per language × companion app is created on the desktop
     (`League of Legends JP - Blitz`); with no companion ticked, plain `League of Legends JP`. Obsolete shortcuts
     of this launcher are removed. If the desktop is not writable (protected folder, OneDrive…), they are created
     in this folder instead.
3. Double-click the shortcut of the language and companion you want.

To add or remove languages or companion apps later: run `install.bat` again.

If detection got it wrong: edit `config.json` (see below) and run `install.bat` again. To force a fresh
detection: delete `config.json` and run again.

The first time you launch in a new language, the Riot Client downloads the text + voice pack
(a few hundred MB). This is expected.

## Companion apps

Several companion apps can live side by side; each shortcut starts exactly one of them after the game, and
**closes the others first** (two overlays at once conflict) — a shortcut without companion closes them all.
For Porofessor this means closing the Overwolf client.
Nothing is ever uninstalled unless you tick the "uninstall" box (or pass `-UninstallOthers`).

| App | Install | Uninstall |
|---|---|---|
| **Porofessor** (Overwolf) | Official Overwolf installer, silent (~10 s) when Overwolf is already present. Without Overwolf, its setup window shows up: follow it (~1 min, a UAC prompt is likely) | **Interactive**: Overwolf opens its own uninstall menu with *Overwolf* **and** *Porofessor* ticked. Untick Overwolf if you use it for other apps, then click Uninstall. The tool never decides for you |
| **Blitz** | `winget install Blitz.Blitz`, silent (~15 s) | Silent |
| **OP.GG** | Official installer from `op.gg`, silent (~10 s) | Silent |
| **Mobalytics** | Official standalone installer from `mobalytics.gg`, silent (~10 s) | Silent |

Safety rules, all enforced by the code:
- the tool refuses to run elevated (administrator) — installers are per-user, and uninstall commands are read
  from the user registry, which any program of yours could alter;
- every binary it runs — a downloaded installer **or** an uninstaller read from the registry — must carry a
  valid Authenticode signature issued to the publisher named in the catalogue (`Overwolf Ltd`/IL, `OP.GG`/KR,
  `Swift Media Entertainment, Inc.`/US for Blitz, `GAMERS NET, INC.`/US for Mobalytics). Unsigned or unexpected →
  refused, with a message telling you to use Windows' own "Installed apps";
- the tool itself never writes to the Windows registry: it only **reads** the `Uninstall` keys;
- if a setup starts the app afterwards (Mobalytics), it is closed again — the app starts with the game.

If automatic installation is impossible (winget missing, network down), the official download page opens in
your browser instead: install the app yourself, the launcher picks it up as soon as it exists.

After an Overwolf app is uninstalled, Overwolf opens a feedback page in the browser; just close it.

Scripted usage (deployment):
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File manage-companion-app.ps1 -Apps blitz,opgg                   # confirmation dialog
powershell -NoProfile -ExecutionPolicy Bypass -File manage-companion-app.ps1 -Apps blitz -UninstallOthers -Force # no dialog at all
powershell -NoProfile -ExecutionPolicy Bypass -File manage-companion-app.ps1 -Apps none -DryRun                 # shows what would happen
powershell -NoProfile -ExecutionPolicy Bypass -File create-shortcuts.ps1 -Locales ja_JP,ko_KR -Companions blitz,opgg
```
Ids: `porofessor`, `blitz`, `opgg`, `mobalytics`, `none`. Exit codes: 0 ok · 1 error · 2 cancelled or refused.

### Adding an app to the catalogue

One entry in `companion-apps.json`; list order is the detection priority.

```json
{
  "id": "opgg",
  "name": "OP.GG",
  "signer":       { "organization": "OP.GG", "country": "KR" },
  "processNames": ["OP.GG"],
  "launch":    { "path": "%LOCALAPPDATA%\\Programs\\OP.GG\\OP.GG.exe", "arguments": "" },
  "detect":    { "registryDisplayNamePattern": "^OP\\.GG", "path": "%LOCALAPPDATA%\\Programs\\OP.GG\\OP.GG.exe" },
  "install":   { "strategy": "download", "url": "https://op.gg/desktop/download/latest", "arguments": "/S /currentuser",
                 "timeoutSeconds": 180, "fallback": "browser", "browserUrl": "https://op.gg/desktop" },
  "uninstall": { "mode": "silent" }
}
```

| Key | Description |
|---|---|
| `signer.organization` / `signer.country` | `O=` and `C=` of the publisher's code-signing certificate, exact and case-sensitive. Read them with `Get-AuthenticodeSignature <exe>` → `SignerCertificate.Subject`. Required for every app: installers and uninstallers are refused otherwise |
| `processNames` | Processes closed before uninstalling, and after an install that started the app |
| `launch.path` / `launch.arguments` | What the launcher starts after the game. `%VAR%` environment variables are expanded |
| `detect.registryDisplayNamePattern` | Regex matched against `DisplayName` of the `Uninstall` registry keys (HKLM, HKLM\WOW6432Node, HKCU). OP.GG and Mobalytics embed their version in the name, hence prefix patterns |
| `detect.path` | Fallback: the app is considered installed if this path exists |
| `install.strategy` | `winget` (+ `wingetId`), `download` (+ `url` in https, `arguments`) or `browser` (+ `browserUrl` in https) |
| `install.fallback` | Strategy used when the main one fails (usually `browser`); its own fields are required too |
| `install.notice` | Text shown in the confirmation before installing (e.g. the Overwolf setup note) |
| `install.timeoutSeconds` | How long to wait for the app to appear after the installer returns (exit codes are unreliable: NSIS uninstallers are asynchronous, Overwolf returns 1223 even on success). Required, > 0 |
| `uninstall.mode` | `silent` (uses `QuietUninstallString`, or `UninstallString` + `/S`) or `interactive` (runs `UninstallString` as is, the publisher shows its own dialog) |
| `uninstall.dialogProcessNames` | Interactive mode: processes of the publisher's dialog to wait for (Overwolf: `OWUninstallMenu`) |
| `uninstall.notice` | Text shown in the confirmation before uninstalling (e.g. the Overwolf warning) |

## `config.json`

```json
{
  "riotClientPath": "C:\\Riot Games\\Riot Client\\RiotClientServices.exe",
  "productSettingsPath": "C:\\ProgramData\\Riot Games\\Metadata\\league_of_legends.live\\league_of_legends.live.product_settings.yaml",
  "companionApps": [
    { "id": "porofessor", "name": "Porofessor", "path": "C:\\Program Files (x86)\\Overwolf\\OverwolfLauncher.exe",
      "arguments": "-launchapp pibhbkkgefgheeglaeemkkfjlhidhcedalapdggh -from-startmenu" },
    { "id": "blitz", "name": "Blitz", "path": "C:\\Users\\<user>\\AppData\\Local\\Programs\\Blitz\\Blitz.exe", "arguments": "" }
  ]
}
```

Backslashes must be doubled (`\\`) — it's JSON. `companionApps` is written by `manage-companion-app.ps1` from the
catalogue; you can still add an entry by hand for an app that is not in the catalogue (any `id` of your choice,
used by `-Companion`). A `config.json` from an older version (single `companionApp` block) is migrated
automatically the next time it is read.

| Key | Description |
|---|---|
| `riotClientPath` | Path to `RiotClientServices.exe`. By default in `C:\Riot Games\Riot Client\`. |
| `productSettingsPath` | The yaml file where Riot stores the LoL language. Always under `C:\ProgramData\Riot Games\Metadata\…` unless the install is unusual. |
| `companionApps[].id` | Identifier used by the shortcuts (`launch-lol.ps1 -Companion <id>`). |
| `companionApps[].name` | Name shown in the splash. Cosmetic. |
| `companionApps[].path` | Executable to start. |
| `companionApps[].arguments` | Launch arguments. Empty string `""` if none. |

If a `path` does not exist on the machine, the launcher skips it and shows a warning in the splash —
the game starts anyway. Same if a shortcut asks for an `id` that is not in the list.

**Another Overwolf app**: keep `OverwolfLauncher.exe` and replace the identifier after `-launchapp`
(visible in the properties of the shortcut the app created in the Start menu).

## Languages

Every language Riot offers is in `locales.json` and can be ticked at install time. The shortcut is
named `League of Legends XX` (XX = country part of the code: `ja_JP` → JP, `ko_KR` → KR), followed by
` - <companion app>` when one is attached.

Icon: `ico/hex-launcher-xx.ico` (lowercase xx) — every language in the catalogue has its flag.
If the icon is missing, the base icon is used.

For a language missing from the catalogue (new Riot locale):
1. add a line to `locales.json` with the exact code as it appears in `available_locales` of the yaml file;
2. (optional) add the flag drawing to `$FlagDrawings` in `make-flag-icons.ps1` and run
   `powershell -NoProfile -ExecutionPolicy Bypass -File make-flag-icons.ps1 -Locales xx_XX`.

## How it works

The Riot Client's "Language" setting only changes the launcher, not the game. The LoL language is read
from `settings.locale` in `product_settings.yaml`, which the Riot Client rewrites every time it closes.
So the launcher does, in order:

1. Close the Riot Client and the LoL client if they are running (otherwise the change would be overwritten).
2. Rewrite `settings.locale` with the requested language (`default_locale`, managed by Riot, is left alone).
3. Start the Riot Client with `--locale=xx_XX` as well, for good measure.
4. Close the other companion apps of `config.json`, then start the one named by `-Companion`, if any.

## Tests

Pester 3.4 ships with Windows PowerShell 5.1 — nothing to install:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "Invoke-Pester -Path tests"
```
Installers, uninstallers, network and registry are mocked: the tests never touch the machine.

## Troubleshooting

- **The game stays in the old language**: the Riot Client was still running during the rewrite.
  The launcher closes it itself, but if a process is stuck, close it by hand (tray icon → Quit) and retry.
- **Nothing happens on double-click**: open a PowerShell terminal in the folder and run
  `.\launch-lol.ps1 -Locale ja_JP` to see the error (config file not found, wrong path…).
- **Garbled characters in the splash or the dialogs** (`Ã©`, `â€¦`): a `.ps1` was re-saved without a BOM.
  Every script (`launch-lol.ps1`, `manage-companion-app.ps1`, `create-shortcuts.ps1`, `lib\*.ps1`) must be
  **UTF-8 with BOM** (VS Code: status bar → encoding → "Save with Encoding").
- **Shortcut icon not up to date**: Windows icon cache. Right-click → Refresh in the folder,
  otherwise sign out/in.
- **"Ne pas exécuter en tant qu'administrateur"**: you started `install.bat` elevated. Start it normally.
- **"winget indisponible"**: App Installer is missing from this Windows. Install it from the Microsoft Store,
  or let the tool open the Blitz download page in your browser.
- **"désinstalleur … non signé"**: the uninstaller found in the registry is not signed by the expected publisher;
  the tool will not run it. Uninstall the app from Windows' "Installed apps" instead.
- **The companion app is still there after "Désinstaller"**: you closed the publisher's dialog without
  confirming (Overwolf), or the uninstall took longer than expected. Nothing else was installed; run `install.bat` again.
- **Test without launching the game**: `.\launch-lol.ps1 -Locale ja_JP -DryRun -YamlPath copy.yaml`
  shows the splash and rewrites the copy, without closing or launching anything.
  `manage-companion-app.ps1 -DryRun` shows the companion app actions without executing them.
