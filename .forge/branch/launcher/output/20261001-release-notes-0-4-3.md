## Hex Launcher 0.4.3 — the HL logo everywhere

- New icon set "HL logo": the HL logo alone, no badge.
- In the setup wizard, the preview of the sets with badges shows where they go (white sample badges).
- The setup wizard window is now called "Configuration - Hex Launcher", like the installer's.
- Installer: HL logo in the corner of its pages and on the panel of the welcome and finish pages; a lighter .exe icon; HL logo in "Installed apps".
- HL logo redrawn: shorter L bar, on every icon.
- 1068 Pester tests.

**Update**: from 0.4.x, it is offered automatically at the next launch (*Install* / *Later*). To pick the new icon set, run the setup wizard again. From 0.3.x, follow the 0.4.0 release notes.
