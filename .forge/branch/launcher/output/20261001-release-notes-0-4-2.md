## Hex Launcher 0.4.2 — shortcuts in the Start menu

- Game shortcuts can go to the Start menu (Hex Launcher folder), the desktop, or both: "Shortcut locations" boxes in the setup wizard, both ticked by default. Unticking a location removes the shortcuts from it.
- The "Hex Launcher" shortcut of the Start menu moves into that folder.
- Uninstalling removes the shortcuts from the desktop and the Start menu.
- The installer carries the HL logo.
- Setup wizard touched up: "Shortcut locations" above "Riot compatibility", lighter left column.
- 1058 Pester tests.

**Update**: from 0.4.x, it is offered automatically at the next launch (*Install* / *Later*). Then run the setup wizard again to place the shortcuts in the Start menu. From 0.3.x, follow the 0.4.0 release notes.
